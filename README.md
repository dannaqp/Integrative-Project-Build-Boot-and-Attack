# Integrative-Project-Build-Boot-and-Attack

Welcome to the main repository of our final Integrative Project. This project is a deep technical exploration covering everything from operating system architecture to offensive cybersecurity.

## Project Specification

Our project is divided into three fundamental and independent areas, designed to demonstrate our proficiency across different levels of computer science:

1. **Your own distro (Cubic):** The build, customization, and packaging of a Linux distribution (Ubuntu 22.04 LTS) specifically designed to provide an out-of-the-box software development environment.
2. **A 64-bit kernel from scratch:** The development and programming of a 64-bit operating system kernel from scratch, interacting directly with hardware at a low level.
3. **Offensive lab (Black Hat Bash):** The deployment of a vulnerable corporate network infrastructure using Docker Compose, followed by the execution of an attack chain involving lateral movement, exploitation, and data exfiltration.

## Branch Organization

To isolate our work environments and keep our version control organized, this repository is structured into four main branches:

* `main`: The current branch. It contains the project overview and centralizes our team's information.
* `rama-distro`: Dedicated to Part 1. It contains the technical documentation, checksums, and evidence of the custom ISO managed by Danna.
* `rama-kernel`: Dedicated to Part 2. It hosts the source code, build directives, and deliverables for the 64-bit kernel managed by Mateo.
* `rama-lab`: Dedicated to Part 3. It contains the audit reports, exfiltrated files, and evidence of the attack vectors managed by Camila.
